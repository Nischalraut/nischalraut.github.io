Objective

Design and build an open-jet subsonic wind tunnel with an integrated gust generator to support low-speed experimental aerodynamics research and CFD validation work.

Methodology

Conceptual sizing and CAD modelling of the flow circuit (settling chamber, contraction, open test section, diffuser, fan/drive section), followed by fabrication and instrumented flow-quality testing in the assembled test section.

Tools

CATIA / SolidWorks for CAD development; wind-tunnel testing and flow-visualization methods for experimental characterisation.

Results

Experimentally validated turbulence intensity of 0.88% in the test section, reported in the existing project portfolio.

Limitations

Open-jet configuration restricts achievable test-section enclosure compared to closed-circuit tunnels; detailed dimensional and instrumentation specifications are documented in the full project report rather than summarised here.

At low angles of attack, flow remains attached over the upper surface. Increase the angle to illustrate flow separation behaviour near the trailing edge.

Objective

Evaluate lift–drag characteristics of a scaled F-15 model across a range of angles of attack using CFD analysis.

Methodology

CAD geometry preparation, mesh generation, and steady-state flow simulation in ANSYS to assess aerodynamic coefficients across the test angle range.

Tools

CATIA/SolidWorks for geometry preparation; ANSYS for CFD simulation.

Results

Comparative lift and drag trends across angle of attack, documented in the full project report. Specific coefficient values are not restated here to avoid summarising beyond the verified source report.

Limitations

Simplified scaled geometry, mesh resolution and turbulence-model assumptions limit direct comparison to full-scale flight data.

Build & Flight Test

Styrofoam Glider — Design and Test Flights

Engineering Objective

Design, build and flight-test a lightweight styrofoam glider to study basic flight stability, control-surface behaviour, and unpowered glide performance.

Methodology

Hand-fabricated airframe from styrofoam sheet; manual centre-of-gravity balancing prior to flight; repeated hand-launched test flights with qualitative observation of trim, glide path and stability.

Test AspectObservation Method
Longitudinal trimVisual observation across repeated hand launches
Glide stabilityQualitative assessment of flight path consistency
CG sensitivityComparative launches after incremental CG adjustment
Tools

Styrofoam airframe material, basic hand tools, manual balancing — no powered propulsion or instrumentation.

Limitations

All results are qualitative and observational; no instrumented data acquisition (e.g. airspeed, load, or trajectory logging) was used in this project.

Software · C Programming

Canteen Billing System

Engineering Objective

Build a console-based canteen billing system in C to automate menu-driven order entry, bill calculation, and basic record-keeping.

Methodology

Procedural programming approach using structs for menu items, a menu-driven console loop for order entry, and file handling for persisting order records between sessions.

Representative excerpt reconstructed for demonstration purposes — refer to the original project source/report for the complete program.
// Representative excerpt — order total calculation
struct MenuItem { char name[30]; float price; };

float calculateTotal(struct MenuItem items[], int qty[], int n) {
  float total = 0;
  for (int i = 0; i < n; i++) {
    total += items[i].price * qty[i];
  }
  return total;
}
Tools

C programming language; local file I/O for record storage.

Limitations

Console-only interface, single-user/local file storage, no concurrency or network capability.
